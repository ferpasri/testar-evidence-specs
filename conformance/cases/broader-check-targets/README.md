# Broader Evaluation Targets

After one completed action and the end of its run, evaluations performed by test oracles target the run, an observation, a state property, a widget, the execution, and the observation sequence. The check results retain passed, unknown, error, and pending statuses. Each result identifies the evaluation's scope; a broad scope does not establish evaluation of every property within it.

Read the events in order and compare the result with `expected.json`.
