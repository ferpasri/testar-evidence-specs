# Flexible origin labels

Four runs use three descriptive origin labels: an explorer, a loan scenario script, and a custom CI job. The strings include mixed capitalization, punctuation, spaces, and accented text. They are source descriptions, rather than values selected from a predefined execution-style list.

All four runs have the same producer. Runs one and four also share an origin label, but their IDs and source-session IDs remain distinct. Preserve all four runs and their exact supplied labels.

The case contains eight events and four finished runs. Compare the summary with `expected.json` and compare complete accepted events with the input to verify the origin strings after recording and reopening. See [run metadata](../../../docs/run-metadata.md).
